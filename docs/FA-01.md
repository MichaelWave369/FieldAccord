# FA-01: frozen review-only contract spine

## Scope

FA-01 is a pure, deterministic local policy assessment. It accepts three closed, versioned JSON envelopes:

1. WorkIntent: human or agent origin, objective, requested capabilities, attention preference, typed context references.
2. CapabilityDeclaration: claimed provider, capability, side-effect class, exact resources. This is untrusted metadata.
3. ActionProposal: an action candidate with exact work ID, capability ID, resource, content digest, and referenced evidence.

Output: WorkReceipt with one of BLOCKED or REVIEW_REQUIRED. There is no ALLOWED, AUTHORIZED, EXECUTED, or SUCCEEDED result.

## Decision order (first matching refusal wins)

- Mismatched WorkIntent ID: WORK_ID_MISMATCH
- Mismatched capability: CAPABILITY_MISMATCH
- Capability not requested: UNREQUESTED_CAPABILITY
- Resource absent from declared exact scope: RESOURCE_OUT_OF_SCOPE
- Evidence reference not in the Intent context: EVIDENCE_NOT_IN_CONTEXT
- Otherwise: REVIEW_REQUIRED / NO_EXECUTION_AUTHORITY

Even the final review outcome grants no permission and causes no action.

## Trust boundaries

- A WorkIntent is not an authority grant; an agent-supplied intent is equally non-authoritative.
- Scope and effect are declared, not independently verified.
- SHA-256 provides reproducible content fingerprints, not a signature, chain of custody, timestamp, or source authenticity.
- An evidence reference is not evidence admission, and its epistemic label is not upgraded.
- Attention policy is a preference, not a durable attention lease or interruption permission.
- The kernel does not download evidence, execute code, write repositories, call tools, or load credentials.
- This release intentionally has no persistence, distributed messaging, live authorization, or connector integration.
